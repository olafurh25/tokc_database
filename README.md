# The Old King's Crown Card Database

A **fan-made web app and searchable card library** for *The Old King's Crown*, created by **Ólafur Þór Helgason** as a personal, non-commercial project.  
The goal is to give players and fans an easy way to browse, search, and study cards, archetypes, factions, and rules from the world of *The Old King's Crown*.

---

## Overview

This project aims to recreate the atmosphere of *The Old King's Crown* while providing useful tools for exploring its deep design and subtle mechanics.

It includes:

- Card browser and grid view  
- Search and filtering by faction, archetype, traits, cost, and rules text  
- Icon-aware rule rendering (for example, `<day>`, `<night>`, `<autumn>`)  
- Detailed modal views with card art, traits, and lore  
- A responsive and atmospheric interface faithful to the tone of the game  

---

## Purpose

There is currently no official card database or reference site for *The Old King's Crown*.  
This project was created to help players and fans explore the game's mechanics and interactions in greater depth, and to serve as a **community resource** for discussion and discovery.

This is a **non-commercial fan project** made out of admiration for the game and its creators at **Eerie Idol Games**.  
All rights to *The Old King's Crown* name, artwork, and design belong to **Eerie Idol Games**.

---

## Tech Stack

- HTML, CSS, JavaScript  
- JSON data structure for card entries  
- Fully static site (no server required)  
- Uses locally stored images and SVG icons  
- Designed for easy local hosting and modification  

---

## Current Features

- Parallax home screen and top bar  
- Advanced search syntax (fielded and free text)  
- Animated card grid with smooth pagination  
- Modal popups with detailed card information  
- Dynamic rule parsing and icon rendering  
- Responsive layout for desktop and mobile
