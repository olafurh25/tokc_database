Advanced Search Syntax

📖 OLD KING'S CROWN — ADVANCED SEARCH SYNTAX

GENERAL
────────────────────────────────────────
• Fielded search: field:value
• Implicit AND between terms. Use OR and - (NOT).
• Grouping: ( ... )
• Wildcards: * (any chars), ? (single char)
• Numeric ops: = != > >= < <= and ranges: a..b
• Presence: has:field   (negate with -has:field)
• Default target (unfielded words): title + rules + commands

FIELDS & ALIASES
────────────────────────────────────────
title, name, n              → Card title
type, t                     → tarot | hq | kingdom | favor | tactic
faction, f                  → clans | uprising | gathering | nobility

TAROT-ONLY FIELDS (require type:tarot)
archetype, a               → ruse | trader | follower | agent | cavalry | war machine | machine | captain | heir | champion
traits, tr, trait          → resilient | invulnerable | pathfinder
strength, str, s           → number
votes, v                   → number
lore, l                    → number
cost, c                    → number (advanced tarot only)

KINGDOM-ONLY FIELDS (require type:kingdom)
suit, s                    → swords | book | coins

TEXT BOXES
commands, cmd              → command text (day, autumn, night, etc.)
rules, r, oracle           → rules text (supports tokens like , , )
flavor, fl                 → flavor text (tarot/HQ typically)

RELEASE & TAGS
release, set, exp, module  → expansion/module/basegame keywords
tag, tags                  → user tags (free text)
has                        → presence checks (rules, flavor, tag, cost, etc.)
is                         → derived: is:vanilla (no rules & no commands), is:legendary (in title/traits)

TYPE-AWARE BEHAVIOR
────────────────────────────────────────
• archetype/traits/strength/votes/lore/cost only match when type:tarot
• suit only matches when type:kingdom
• Other fields (title/faction/rules/commands/flavor/release/tags) work on any type

OPERATORS & EXAMPLES
────────────────────────────────────────
AND (default):
  f:nobility type:tarot strength>=2

OR:
  (archetype:ruse OR archetype:agent) type:tarot

NOT:
  -fl:"winter"   -has:flavor   -tag:deprecated

Wildcards & phrases:
  title:king*     rules:""     traits:resilient

Ranges & numbers:
  votes=2..4      cost<=3       strength>1

Presence:
  has:rules       -has:flavor   has:tag

Release:
  release:basegame
  release:"Wild Kingdom"

Kingdom examples:
  type:kingdom suit:coins
  type:kingdom f:gathering rules:river

Tarot examples:
  type:tarot archetype:ruse traits:resilient
  type:tarot strength>=2 votes=2..4
  type:tarot -has:flavor is:vanilla

DEFAULT SEARCH
────────────────────────────────────────
Unfielded words search: title + rules + commands
  example:  king deploy  → title/rules/commands contain both words
